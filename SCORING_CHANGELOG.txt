LMC scoring correction — 2026-11-12

Implemented the agreed response-time scoring rules in the Zanti dashboard version.

Scoring:
  full_score_window_ms = 5,000 + 1,000 * (level - 1)
  deadline_ms = responseLimitForLevel(level), shared by the countdown and timeout
  if response_time_ms <= full_score_window_ms: points = 100
  else if response_time_ms >= deadline_ms: points = 0
  else: points = round(100 * (deadline_ms - response_time_ms) /
                       (deadline_ms - full_score_window_ms))

The full-score window is 5 seconds at Level 1 and increases by 1 second per level.
After that window, points decrease linearly to zero at the response deadline.
A timeout earns zero points.

The adaptive Intelligent System remains removed, as requested. The existing
non-adaptive level response deadline is retained: 15 seconds base at Level 1,
+1 second per level up to 30 seconds, plus the existing 5-second grace period.

Preserved:
  - Zanti's redesigned dashboard and all other files/changes
  - Existing backend, database schema, API payloads, and score display
  - Existing game progression, lives, sequence handling, and hardware settings

Only the firmware scoring/deadline consistency and this changelog were changed.
Hardware and live-backend tests are still required before deployment.
