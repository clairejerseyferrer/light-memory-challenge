# Team Contributions & Project Roles

## Project Team

Light Memory Challenge was developed through collaborative work across game design, embedded systems development, IoT hardware fabrication, intelligent system design, web development, database integration, interface design, testing, and deployment.

Each member contributed to a different aspect of the project, with responsibilities coordinated to ensure that the hardware, firmware, software, and intelligent system components worked together as a unified application.

## Collaborative Development

Although responsibilities were distributed according to each member's primary contribution, the project was developed collaboratively. Hardware testing, firmware integration, interface refinement, gameplay evaluation, and system validation involved coordination and feedback among team members.

The final system reflects the combined contributions of the team across game design, IoT hardware, embedded programming, intelligent system development, software integration, interface design, testing, and deployment.
